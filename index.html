你好，我是唐婷婷，日语专业出身，做了 8 年 UI 设计。最初在留学机构做日语文案翻译，后来靠自学转向 UI 设计，再把 AI 接进自己的工作流。

从产品 0 到 1、设计系统，到品牌 IP、运营物料，我都上手。这两年把 AI 接进了自己的工作流——需求分析、插画、H5、原型验证，也自己用 Vibe Coding 做小产品：塔罗测试、记账工具、拼豆图案工具，从需求到交付一个人走完。

朋友说我温和，聊起专业又很较真。我觉得设计师就该这样：手要软，标准要硬。
