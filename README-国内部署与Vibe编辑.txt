作品集国内部署与 Vibe Coding 编辑说明

一、部署
1. 将 dist 文件夹整体上传到国内静态网站托管、对象存储静态网站或公司服务器。
2. 网站入口文件是 dist/index.html。
3. 这个作品集页面本身只使用本地 HTML、CSS、JS 和图片，可以直接在国内部署。

二、编辑 Vibe Coding 项目
1. 打开「作品展示」里的「Vibe Coding」分类。
2. 点击「编辑内容」，再点击任意卡片右上角的「编辑」。
3. 可以修改：项目名称、标签、移动端或网页端样式、卡片格式文字、项目说明、体验网址、卡片色调和页面预览图。
4. 两张「Vibe Coding 项目 01 / 02」是预留卡位，填好内容并上传截图后就可以直接使用。
5. 「保存到本机」会保存当前浏览器里的修改；「导出配置」可以把文字配置交给同事。

三、国内访问地址
现有四个示例项目的体验网址仍是原来的演示地址。将项目部署到国内站点后，在编辑器的「体验网址」里替换成新的国内地址即可，作品集卡片会直接跳转到新地址。

四、预览图建议
移动端项目上传竖屏首页截图，网页端项目上传宽屏首页截图。卡片会自动统一预览比例，并根据选择的端类型调整展示方式。
